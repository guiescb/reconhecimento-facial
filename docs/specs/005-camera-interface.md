# 005 - Interface

Status: rascunho (atualizar conforme a implementacao)

## Requisitos
- RF1: exibir a imagem da camera (ou arquivo) com o nome da pessoa reconhecida ou "desconhecida".
- RF2: acoes de cadastrar, reconhecer e excluir pessoa.
- RF3: tratar camera indisponivel com mensagem clara.

## Criterios de aceitacao
- Iniciar sem cadastros mostra "Nenhuma pessoa cadastrada".
- Camera indisponivel -> mensagem de erro, sem travar.
- A tecnologia de interface escolhida esta justificada em ADR.
